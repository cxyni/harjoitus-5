# Oppimispäiväkirja: Git projektissa

__Mitä hyötyä voisi olla versionhallinnasta, jos kehität projektia yksin?__

Versionhallinta auttaa seuraamaan mitä muutoksia projektiin on tehnyt. Jos jokin menee pieleen, voi helposti palata vanhaan versioon. Se auttaa myös muistamaan mitä on tehnyt aikaisemmin.

__Mitä hyötyä voisi olla versionhallinnasta, jos projektissa on useita kehittäjiä?__

Se helpottaa yhteistyötä. Jokainen voi tehdä omia muutoksia ilman että muiden työ menee sekaisin. Lisäksi näkee helposti kuka on tehnyt mitäkin muutoksia.

__Miten järjestäisit projektitiimin versionhallinnan 3-4 hengen ohjelmistoprojektikurssilla? Laadi tiimiläisille lyhyt ohje, miten projektissa toimitaan.__

Kaikki tekevät omat muutokset omassa branchissa. Päähaaraan ei tehdä suoraan muutoksia. Kun työ on valmis, tehdään pull request GitHubiin. Muut tiimiläiset voivat katsoa muutokset läpi ennen kuin ne yhdistetään. Commit-viestit kirjoitetaan selkeästi.
