# Oppimispäiväkirja: Hajautettu git

__Mikä osion tehtävissä oli vaikeaa ja mikä helppoa? Mikä auttoi minua oppimaan? Miten selvitin esteet, jotka vaikuttivat tehtävän suorittamiseen?__

Helpointa oli tehdä GitHub-repo ja lisätä sinne tiedosto. Vaikeinta oli saada oma paikallinen repo yhdistettyä GitHubiin oikein ja tajuta, missä kansiossa komennot pitää tehdä.

Opin parhaiten niin, että etenin rauhassa vaihe kerrallaan ja tarkistin komennot. Sain ongelmat ratkaistua, kun korjasin etärepon osoitteen ja tein komennot oikeassa kansiossa.

## Osiossa käyttämäni Git-komennot

| Komento | Kuvaus |
| --------| ------ |
| git remote add origin| Lisää etärepositorion |
| git remote -v| Näyttää etärepositorion osoitteet|
| git push -u origin main | Vie paikallisen haaran GitHubiin | 
| git fetch | Hakee muutokset etärepositoriosta |
| git checkout origin/main | Näyttää etähaaran sisällön | 
| git merge origin/main | Yhdistää muutokset paikalliseen haaraan |
